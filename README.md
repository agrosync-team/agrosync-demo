# Agro-Sync Biomass 🌱🚜
**"GrabShare ของเศษพืช ให้ชาวบ้านไม่ต้องเผา และโรงไฟฟ้าได้เชื้อเพลิง"**

Agro-Sync คือระบบที่นัดรถอัดฟางมาเก็บเศษพืช (ฟางข้าว, ใบอ้อย, เหง้ามันสำปะหลัง) ของหลาย ๆ บ้านในรอบเดียว แล้วส่งไปขายเป็นเชื้อเพลิงให้โรงไฟฟ้าชีวมวล โดยใช้ดาวเทียมกับ AI บอกล่วงหน้าว่าแปลงไหนจะพร้อมเมื่อไหร่ เพื่อรวม "ล็อต" ให้คุ้มค่าขนส่ง

## 🚨 ปัญหาที่เราแก้
ชาวบ้านไม่ได้อยากเผา แต่ต้องกำจัดเศษพืชก่อนไถรอบใหม่ และไม่มีใครมารับซื้อเพราะปริมาณน้อย ขณะที่โรงไฟฟ้าชีวมวลอยากได้เศษพืชเป็นเชื้อเพลิง แต่แต่ละบ้านมีนิดเดียวและพร้อมไม่ตรงกัน รถอัดฟางเลยไม่คุ้มที่จะมาเก็บ

*เราไม่ได้มาห้ามเผา แต่เราทำให้ไม่ต้องเผา*

## 💡 ใครได้อะไรจากระบบนี้
*   **ชาวบ้านรายเล็ก** มีคนมาเก็บเศษพืช ได้เงิน ไถนาได้โดยไม่ต้องเผา ใช้งานง่ายผ่าน LINE
*   **คนรถอัดฟาง** รู้ล่วงหน้าว่า "ล็อต" ไหนพร้อม วิ่งรถเต็มคันทุกเที่ยว ไม่ต้องวิ่งหาแปลงเอง
*   **โรงไฟฟ้าชีวมวล** รู้ล่วงหน้าว่าจะมีเชื้อเพลิงเข้ามากี่ตันในแต่ละสัปดาห์
*   **ชุมชน** ฝุ่น PM 2.5 และการเผาลดลง

## ⚙️ สถาปัตยกรรมระบบ (ตา - สมอง - ปาก)

ระบบทำงานเหมือนคน 1 คน ดังนี้
1.  **👀 ตา (ข้อมูลเข้า)** 
    *   ดาวเทียม (จุดความร้อนและภาพแปลงจาก NASA FIRMS, Sentinel-2)
    *   ชาวบ้านแจ้งข้อมูลแปลงผ่าน LINE
    *   ข้อมูลสภาพอากาศและสถิติ
2.  **🧠 สมอง (AI และฐานข้อมูล)** 
    *   ทายวันพร้อมเก็บและความเสี่ยงเผา (ล่วงหน้า 3-7 วัน)
    *   ประเมินปริมาณชีวมวล (ตัน และ MWh)
    *   จัดกลุ่มแปลงที่ใกล้กันและพร้อมช่วงเดียวกันเป็น **"ล็อต"**
3.  **🗣️ ปาก (บอกผล)** 
    *   แจ้งเตือนชาวบ้านผ่าน LINE (รถเข้าวันไหน ให้กดตอบรับ)
    *   แสดงเว็บแผนที่ให้คนรถรับงาน
    *   ส่งพยากรณ์ปริมาณเชื้อเพลิงให้โรงไฟฟ้า

## 💻 ข้อมูลไฟล์ในเดโม (Demo)

เดโมนี้ใช้ **ข้อมูลจำลอง** ในพื้นที่ ต.ผาเสวย (เพื่อการนำเสนอประกวด)

### 1. `liff.html` (ฝั่งเกษตรกร)
หน้าเว็บแอปพลิเคชันสำหรับให้ชาวบ้าน **"ลงทะเบียนแปลง"** ผ่านระบบ LINE LIFF 
*   ชาวบ้านสามารถเลือกชนิดพืช (ข้าว, อ้อย, มันสำปะหลัง), ระบุจำนวนไร่, คาดการณ์วันเก็บเกี่ยว
*   ปักหมุดตำแหน่งแปลงบนแผนที่ดาวเทียม (Leaflet)
*   ข้อมูลจะถูกส่งไปยัง Google Apps Script (API) 

### 2. `index.html` (ฝั่งคนรถอัดฟาง / โรงไฟฟ้า)
หน้าแดชบอร์ด **"แผนที่ล็อตสำหรับคนรถ"** แสดงผลผ่าน Web Browser
*   ดึงข้อมูลจาก API มาแสดงผลเป็นวงกลม (ล็อต) และจุด (แปลง) บนแผนที่
*   **แสดงสถานะล็อตสีต่างๆ** ครบขั้นต่ำรอรถ (เขียว), ยังไม่ถึงขั้นต่ำ (ส้ม), นัดรถแล้ว (น้ำเงิน), เก็บแล้ว (เทา)
*   **ระบบรับงาน** คนรถสามารถเลือกบริษัทตัวเอง กำหนดวันเข้าเก็บ และกด "รับงานล็อตนี้" ได้ทันที
*   **พยากรณ์เชื้อเพลิง** มีแท็บสรุปตัวเลขพยากรณ์ตัน/MWh ที่จะเข้าโรงไฟฟ้าใน 7-14 วันข้างหน้า พร้อมเทียบข้อมูลผลจากดาวเทียมจริง (Sentinel-2)

### 3. Backend (Google Sheets & Apps Script)
*   ในเวอร์ชันเดโม ใช้ Google Sheets เป็นฐานข้อมูล (สมุดจด) และใช้ Google Apps Script เป็น API ในการรับส่งข้อมูลและจัดกลุ่มล็อตด้วยกฎง่ายๆ (ระยะทาง ≤ 3 กม., เวลา ≤ 7 วัน)

## 🚀 วิธีการรันเดโม
1.  **ฝั่งแผนที่คนรถ** เปิดไฟล์ `index.html` ด้วย Web Browser ใดก็ได้ (รองรับการใช้งานบนมือถือและเดสก์ท็อป) ระบบจะดึงข้อมูลจำลองและรีเฟรชตัวเองอัตโนมัติทุกๆ 15 วินาที
2.  **ฝั่งลงทะเบียนแปลง** นำไฟล์ `liff.html` ไปโฮสต์ (เช่น GitHub Pages) และตั้งค่า Endpoint URL ใน LINE Developers Console เพื่อเปิดใช้งานผ่านแอป LINE บนมือถือ
